# Python FAQ Chatbot

An AI-powered FAQ chatbot built using Python and Streamlit.

## Features
- Answers basic Python questions.
- Uses TF-IDF vectorization.
- Uses cosine similarity to find matching questions.
- Provides a fallback response for unrelated questions.

## Technologies
- Python
- Streamlit
- Scikit-learn

## Installation
pip install -r requirements.txt

## Run
streamlit run app.py
